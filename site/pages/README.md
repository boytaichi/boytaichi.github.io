# prospereum.io — static pages (GitHub Pages layout, sheet v2 row 1)

Plain HTML + ES modules, no bundler, no web fonts, no third-party loads (row 7). Drops into the `prospereum-website` repository as a branch once Fire has read access; until then it lives here and is posted to #prospereum as a zip.

- `token/` — Token page per Token Page Spec v6: `config.js` (the only typed constants: endpoints, addresses, selectors), `token-logic.mjs` (pure: call list, decoding, formats, backlog, epoch window, fixed copy), `token.js` (browser: chainId check, one `eth_blockNumber` per refresh, every getter at that block, 60 s refresh + focus, "Stale — last successful snapshot" on failure, upstream identity from the Worker's `X-Prospereum-Upstream` header), `index.html` (layout; Treasury row = live rounded `balanceOf`, address unlinked; footer sentence verbatim, row 6).
- `index.html` (Overview = Site Copy & IA v1 §2.1 Home + §2.5 "Where you can use it", verbatim; live strip = total supply / emitted / cap / block), `protocol/` (Protocol = §2.3 "How you earn it", verbatim, plus a read-only live block — released, reserve, treasury, split, epoch state, timelocks — through the same constants and decoding as the Token page) and `about/` (About = §2.2 "What PSRE is", verbatim, plus the launch / audit facts; static, no chain read). Added 29 Oct.
- `shared/live-logic.mjs` (pure: `subsetCalls` filters the Token page's call list to the keys a page asks for — never a new selector; `deriveSubset`, `overviewStrip`, `snapshotLine`) and `shared/live.js` (browser glue: same endpoint order, chainId check, one block per refresh, 60 s, stale banner; the page declares `data-live-keys="overview|protocol"`). Tests: `node --test shared/test/live-logic.test.mjs` (4).
- `use/` (**Where you can use it** = Site Copy & IA v1 §2.5, verbatim, plus the IA §1 live datum — PartnerVault count: `activeVaultCount` / `vaultCount` read from the factory at one block through `shared/live.js` with `data-live-keys="use"`; a "Live partners" list that reads "No partner vault is live yet" until one is). Added 30 Oct — the sixth and last page of the copy.
- `shared/chrome.mjs` — the ONE nav + footer definition (six nav entries in order; footer sentence verbatim from sheet v2 row 6). `node scripts/stamp-chrome.mjs` rewrites every page's `<nav>`/`<footer>` from it (`--check` fails on drift). Never edit a page's nav by hand.
- `test/site.test.mjs` — integration: shared chrome on every page, every internal href/src resolves, a local static serve answers 200 for all six pages and headless Chrome loads each with no JavaScript error (network blocked → live blocks degrade to "—").
- `site.css` — shared styles.
- `scripts/copy-drift.mjs` (+ `test/copy-drift.test.mjs`) — **copy drift**: every sentence of Site Copy & IA v1 §2.1 (Home), §2.2 (About), §2.3 (Protocol) and §2.5 (Use, and its echo on Home) must appear verbatim on its page; 69 sentences checked. Deliberate deviations live in `scripts/copy-drift.allow.json` with the reason (three: the Home live strip is read from the chain, not typed; `partnerships@` is unpublished on Home and Use per Decision Sheet v2 row 6 — the pages point to Partners & Developers). The Token page (§2.4) and Partners page (§2.6) are governed by the later accepted baselines — Token Page Spec v6 and SDK Spec v4 — and are not diffed against v1 copy. A stale allow entry fails the check.
- `scripts/build-zip.mjs [name]` — **release candidate**: chrome `--check` → all page tests (22) → copy drift → Worker tests (11) → `../dist/<name>.zip` (pages/ + worker/ + DEPLOY.md + RELEASE.txt) with `<name>.zip.sha256`. `../DEPLOY.md` is the one-page deploy + verify note for Kin/Jason.

**Page map (six):** `/` Overview · `/token/` Token · `/partners/` Partners & Developers · `/use/` Where you can use it · `/protocol/` Protocol (How you earn it) · `/about/` About (What PSRE is). Team access = the existing password gate, footer only, untouched.
- Tests (all, from `pages/`): `node --test token/test/token-logic.test.mjs partners/test/partners-logic.test.mjs shared/test/live-logic.test.mjs test/copy-drift.test.mjs test/site.test.mjs` (22). Token page alone: `node --test token/test/token-logic.test.mjs` (fixtures = the block 52,919,775 reads printed in spec v6). Live check: `node token/test/live-check.mjs` (public fallback endpoint; prints `derive` for the current block).
- The page's primary endpoint is `/rpc` = the Worker in `../worker/`; on Pages without the Worker route it falls through to the public endpoints (fallback order per spec v6 §6).
- `scripts/verify-deploy.mjs <origin> [--rpc <worker>/rpc]` — DEPLOY.md §4 steps 1, 5 and the Worker route against a deployed origin: six pages 200, stamped nav + footer sentence present (same `shared/chrome.mjs` definition), scripts same-origin or Cloudflare Web Analytics; GET /rpc → 405, eth_chainId → 0x2105, disallowed method → 4xx. Proven 2 Nov against a local static serve (24 checks).

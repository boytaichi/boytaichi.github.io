# prospereum.io RPC proxy (Cloudflare Worker)

Build baseline: Site Decision Sheet v2 (2026-10-25) row 2; Token page spec v6 §6; SDK spec v4 addresses; Kin's PR #1 review (2026-11-11/12), findings 2, 4, 6, 7, 8, 11.

- `src/index.js` — the Worker, no dependencies. **Allowlist = the pages' call manifest**: it imports `../../pages/shared/call-manifest.mjs`, which derives every (contract, selector) pair from `pages/token/config.js` (`GETTERS`) and `pages/partners/config.js` (`FACTORY_GETTERS`, `VAULT_GETTERS`). A getter added to a page config is admitted by the Worker in the same commit; nothing is typed twice. Multicall3 `aggregate` / `aggregate3` / `tryAggregate` are decoded and every inner target+selector checked (nesting refused). **Dynamic PartnerVault targets**: the four per-vault selectors (`owner ecosystemBalance cumS getCustomerVaultCount`) are admitted only after one upstream `factory.vaultActive(target)` read at the same pinned block says true; verdicts are cached 60 s in a bounded map; an arbitrary address is never admitted. `eth_call` only with an explicit hex block number or a plain `{blockHash}` (`requireCanonical` rejected); `eth_getBlockByNumber` concrete number + `false` only; batches rejected.
- Limits: body ≤ 64 KiB; direct calldata ≤ 260 bytes; Multicall3 calldata ≤ 32 KiB, ≤ 64 inner calls of ≤ 260 bytes; in-isolate cache = bounded LRU (1,024 entries) keyed by `method:sha256(params)`; caller's `id` preserved; only validated upstream results cached (60 s).
- Bindings validated on every request (`SITE_ORIGIN` exact origin, `UPSTREAM_URL` http(s), `CACHE_TTL_SECONDS` 1–3600, `RATE_LIMITER` present) — any failure → `503 {"error":"service misconfigured"}`. `DEV_ALLOW_NO_RATE_LIMIT="true"` bypasses only the rate-limiter check, for local `wrangler dev`. `GET …/health` → bindings + one allowed and one rejected call shape, no upstream call.
- Upstream: 10 s timeout, HTTP 200 required, JSON-RPC 2.0 shape + per-method result validation, block headers field-filtered; failures answer fixed messages (`upstream unavailable`, `upstream returned an invalid response`); upstream JSON-RPC errors become `execution reverted` or `upstream rpc error` (integer code kept, `data` dropped). The upstream URL/key never appears in a response, error or log line. Upstream identity in `X-Prospereum-Upstream` (exposed via CORS); CORS = site origin only (foreign origin → 403); allowlist rejection → **HTTP 400, JSON-RPC -32602**.
- Tests (Node ≥ 20, nothing to install), from `worker/`: `node --test test/*.test.mjs` — `worker.test.mjs` (Kin's three acceptance tests + the row-2 rules, 11), `manifest.integration.test.mjs` (every page call generated from the page code and replayed through `handle()` at one pinned block; negative cases, 6), `hardening.test.mjs` (limits, bounded cache, mandatory rate limit, bindings, health, upstream sanitising, requireCanonical, 400 contract, 10). 27/27 on 2026-11-12.
- `wrangler.toml` — routes (`/rpc` and `/rpc/*` for the health probe) / vars template. `UPSTREAM_URL` is a Worker secret set by Jason (`wrangler secret put UPSTREAM_URL`). `npx wrangler deploy --dry-run` bundles the shared manifest from `site/pages`.

Adding a getter = one line in the page config (+ its page test); the Worker admits it through the manifest and `manifest.integration.test.mjs` proves it. When the PSRE-native factory goes live its address changes in `pages/token/config.js` only.
